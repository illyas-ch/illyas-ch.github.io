Content-Based Collaborative Filtering
This recommender was trained entirely on the IMDB Top 1000 dataset using Python (pandas + scikit-learn). No external API is used — recommendations are computed from a pre-trained cosine similarity matrix embedded directly in this file.
📊
1. Data Ingestion
999 movies loaded from IMDB Top 1000 CSV. Missing values cleaned, runtime parsed to integers, genres split into arrays.
🔢
2. Feature Engineering
MultiLabelBinarizer encodes 21 genres (weighted 2×). MinMaxScaler normalises rating, Metascore, year, runtime, and vote count.
📐
3. Similarity Matrix
999×999 pairwise cosine similarity matrix computed with scikit-learn. Top-15 neighbours per film are stored compactly.
🎯
4. Inference
At query time, the app ranks stored neighbours and re-filters by your genre / era / rating preferences in milliseconds — no server needed.

Tech Stack
Python: pandas, scikit-learn (MultiLabelBinarizer, MinMaxScaler, cosine_similarity)
AI Concepts: Content-based filtering, TF-IDF-style genre encoding, cosine similarity
Dataset: IMDB Top 1000 (kaggle) — 999 films, 16 features
Deployment: Fully client-side HTML — model pre-trained, weights embedded as JSON
